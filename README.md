# 🎓 Attendance System - University of Kelaniya (UoK)

A web-based Attendance Management System developed to streamline student attendance tracking and management within the University of Kelaniya. The system provides an efficient and user-friendly platform for lecturers, administrators, and students to manage attendance records digitally.

## 📋 Overview

Traditional attendance marking methods are often time-consuming and prone to errors. This project aims to digitize the attendance process by providing:

- Student attendance tracking
- Course and subject management
- Attendance report generation
- User authentication and role-based access
- Attendance analytics and monitoring

## ✨ Features

### 👨‍🏫 Lecturer Features
- Mark student attendance
- View attendance history
- Generate attendance reports
- Manage course enrollments

### 👨‍🎓 Student Features
- View personal attendance records
- Check attendance percentages
- Monitor eligibility requirements

### 👨‍💼 Administrator Features
- Manage students and lecturers
- Create and manage courses
- Generate system-wide reports
- User management and access control

## 🚀 Installation

```bash
git clone https://github.com/osadaRajapaksha/Attendance-System-UoK.git
cd Attendance-System-UoK
```

### Configure Database

```sql
CREATE DATABASE attendance_system;
```

Import the database script and update the configuration file with your database credentials.

## 📊 System Workflow

1. User logs into the system.
2. Lecturer selects a course/session.
3. Attendance is marked for students.
4. Records are stored in the database.
5. Students and administrators can view reports.
6. Attendance statistics are generated automatically.
